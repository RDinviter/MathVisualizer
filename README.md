# 📐 MathVisualizer — Анимация решения математических задач

Программная визуализация пошагового решения задач по тригонометрии и алгебре с параметром с использованием **Manim** и **LaTeX**.

---

## О проекте

Проект демонстрирует автоматизированное создание анимированных образовательных материалов. Каждая сцена — это полноценное решение математической задачи, где формулы, графики и геометрические объекты генерируются кодом.

###  Возможности
- **Пошаговая анимация** решений с плавными переходами
- **Интерактивные графики** с движущимися элементами (`ValueTracker`, `always_redraw`)
- **Тригонометрическая окружность** с отбором корней
- **Графический метод** решения задач с параметром
- **Динамическое выделение** точек пересечения кривых

## 📊 Реализованные задачи

### 1. Тригонометрическое уравнение

**Файлы:** `triga_a.py`, `triga_b.py`

**Условие:**
- **а)** Решить уравнение: $2\cos\left(x-\frac{\pi}{3}\right) + 2\sin\left(\frac{3\pi}{2} + x\right) = 0$
- **б)** Найти корни на отрезке $\left[-2\pi; -\frac{\pi}{2}\right]$

**Что анимируется в `triga_a.py`:**
- Применение формулы приведения: $\sin\left(\frac{3\pi}{2} + x\right) = -\cos x$
- Формула косинуса разности: $\cos\left(x - \frac{\pi}{3}\right) = \cos x \cdot \cos\frac{\pi}{3} + \sin x \cdot \sin\frac{\pi}{3}$
- Алгебраические преобразования с эффектом `TransformFromCopy`
- Деление на $\cos x \neq 0$ с обоснованием
- Получение ответа: $x = \frac{\pi}{6} + \pi k, \ k \in \mathbb{Z}$
- Эффект "пролистывания" решения вверх

**Что анимируется в `triga_b.py`:**
- Построение тригонометрической окружности с осями
- Выделение дуги отрезка $\left[-2\pi; -\frac{\pi}{2}\right]$ жёлтым цветом
- Отметки ключевых углов: $0$, $-\pi$, $-\frac{3\pi}{2}$, $-\frac{\pi}{2}$, $-2\pi$
- Визуализация корней $-\frac{11\pi}{6}$ и $-\frac{5\pi}{6}$ на окружности
- Пунктирная линия между корнями
- Вычисление корней через подстановку $k = -2$ и $k = -1$
- Финальный ответ в рамке

### 2. Задача с параметром (графический метод)

**Файлы:** `parametr.py`, `parametr_graf.py`

**Условие:** Найти все значения параметра $a$, при которых уравнение
$$ax^4 + x^3 + (a^3 - 2a)x^2 + (a^2 - 2)x = ax^3 + x^2 + (a^3 - 2a)x + a^2 - 2$$
имеет ровно 2 решения.

**Что анимируется в `parametr.py`:**
- Перенос всех слагаемых в левую часть
- Пошаговое разложение на множители:
  - Группировка слагаемых
  - Вынесение общих множителей
  - Получение $(x - 1)(ax + 1)(x^2 + a^2 - 2) = 0$
- Переход к совокупности уравнений:
  - $x = 1$
  - $a = -\frac{1}{x}$
  - $x^2 + a^2 = 2$
- Анимация с эффектом `ease_out_elastic`

**Что анимируется в `parametr_graf.py`:**
- Построение системы координат $xOa$
- График окружности $x^2 + a^2 = 2$ (радиус $\sqrt{2}$)
- График гиперболы $a = -\frac{1}{x}$ (две ветви)
- Вертикальная прямая $x = 1$
- **Движущаяся горизонтальная прямая** $a = \text{const}$ (красная, `ValueTracker`)
- **Динамические точки пересечения** (`always_redraw`):
  - 🔵 Синяя точка на прямой $x = 1$
  - 🟢 Зелёная точка на гиперболе $a = -1/x$
  - 🟡 Жёлтые точки на окружности $x^2 + a^2 = 2$
- Анализ количества решений при ключевых значениях $a$:
  - $a = -\sqrt{2}$: 3 решения (касание окружности)
  - $a = -1$: 2 решения
  - $a = 0$: 3 решения (гипербола не определена)
  - $a = 1$: 2 решения
  - $a = \sqrt{2}$: 3 решения (касание окружности)
  - $a = 2.5$: 2 решения
- Подсветка синими линиями критических значений
- Финальный ответ: $a \in \{-1; 1\} \cup (-\infty; -\sqrt{2}) \cup (\sqrt{2}; +\infty)$
