# 📐 MathVisualizer — Анимация решения математических задач

Программная визуализация пошагового решения задач по тригонометрии и алгебре с параметром с использованием **Manim** и **LaTeX**.

---

## 🎯 О проекте

Проект демонстрирует автоматизированное создание анимированных образовательных материалов. Каждая сцена — это полноценное решение математической задачи, где формулы, графики и геометрические объекты генерируются кодом.

###  Возможности
- **Пошаговая анимация** решений с плавными переходами
- **Интерактивные графики** с движущимися элементами (`ValueTracker`, `always_redraw`)
- **Тригонометрическая окружность** с отбором корней
- **Графический метод** решения задач с параметром
- **Динамическое выделение** точек пересечения кривых
